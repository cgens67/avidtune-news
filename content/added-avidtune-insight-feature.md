# Added AvidTune Insight feature

We have introduced the AvidTune Insight feature in the latest build. This functions similarly to Spotify Wrapped, providing a summary of your listening habits and statistics over time.

Please note that this feature is currently in an experimental beta phase. As of this release, it is highly broken and may not display data correctly or function as intended. Expect crashes and incomplete metrics while navigating this screen. We are actively working on resolving these issues and stabilizing the feature for future updates.
