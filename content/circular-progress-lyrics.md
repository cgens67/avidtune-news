# Circular Progress Indicator Added

After a long continuous tweaking, this feature has finally been added! This feature will be in version 1.0.2.

We know that waiting during long instrumental gaps can sometimes feel disconnected from the playback experience. To improve this, we've implemented a sleek, wavy circular progress indicator that automatically appears during these extended musical pauses. 

Not only does this give you a satisfying visual cue of the ongoing track progression, but it also perfectly matches your dynamic theme colors. 

We hope this small but meaningful addition enhances your listening experience. Stay tuned for more upcoming updates!
